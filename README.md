# Inspired - Онлайн магазин нижнего белья

## Описание проекта
**Inspired** - это учебный одностраничный веб-сайт, созданный в рамках онлайн-школы METHED. Этот проект представляет собой современный интернет-магазин нижнего белья, который демонстрирует использование современных технологий веб-разработки.

---

## 1. Макет
Сайт был разработан по макету, предоставленному в **Figma**. Это позволило создать визуально привлекательный и функциональный интерфейс, который соответствует современным стандартам дизайна.

---

## 2. Стили
Проект использует **SCSS** для стилизации. Это позволяет легко управлять стилями и поддерживать их в чистоте и порядке. С помощью адаптивного дизайна сайт корректно отображается на различных устройствах, обеспечивая удобство для пользователей. Также используется **PostCSS**, что помогает в автоматизации задач, таких как автопрефиксация и минификация стилей.

---

## 3. JavaScript

Вся интерактивность на сайте реализована с использованием **JavaScript (ES6 и выше)**. Этот современный стандарт позволяет писать более чистый, эффективный и понятный код. Ниже представлены ключевые аспекты использования JavaScript в проекте:

### 3.1. Работа с DOM
- **Манипуляция элементами**: Используя JavaScript, мы получаем доступ к элементам DOM-дерева, что позволяет нам изменять их свойства и содержимое. Например, мы можем скрывать или отображать элементы в зависимости от действий пользователя.
- **Создание новых элементов**: JavaScript позволяет динамически создавать новые элементы на странице, добавляя их в нужные места в DOM. Это полезно для отображения товаров, отзывов и других динамических данных.

### 3.2. Управление событиями
- **Обработка событий**: JavaScript позволяет отслеживать и обрабатывать события, такие как клики, наведение мыши и ввод данных. Это делает интерфейс более интерактивным и отзывчивым.
- **Создание пользовательских интерфейсов**: С помощью событий мы можем создавать интерактивные элементы, такие как кнопки, формы и модальные окна, которые улучшают пользовательский опыт.

### 3.3. Объектно-ориентированное программирование (ООП)
- **Использование классов**: В проекте применяются классы для организации кода и создания объектов. Это позволяет создавать более структурированные и поддерживаемые приложения.
- **Инкапсуляция и наследование**: Мы используем принципы инкапсуляции и наследования для управления состоянием объектов и переиспользования кода, что упрощает разработку и тестирование.

### 3.4. Архитектура MVC
- **Модель (Model)**: Отвечает за управление данными и бизнес-логикой. Здесь происходит взаимодействие с API для получения и обработки данных.
- **Представление (View)**: Отвечает за отображение данных пользователю. JavaScript используется для обновления интерфейса в ответ на изменения в модели.
- **Контроллер (Controller)**: Обрабатывает взаимодействие пользователя и управляет потоком данных между моделью и представлением. Он реагирует на события и обновляет интерфейс в соответствии с действиями пользователя.

### 3.5. Шаблонные строки и интерполяция
- **Шаблонные строки**: Используем шаблонные строки для удобного формирования HTML-кода. Это позволяет вставлять динамические данные в разметку без необходимости конкатенации строк.
- **Интерполяция**: С помощью интерполяции мы можем легко добавлять переменные и выражения в строки, что делает код более читаемым и удобным для поддержки.

### 3.6. Маршрутизация
- **Использование Navigo**: Для управления навигацией в приложении используется библиотека **navigo**. Она позволяет определять маршруты и обрабатывать переходы между страницами без полной перезагрузки, что делает приложение более отзывчивым и быстрым.

---

Эти аспекты JavaScript в проекте **Inspired** обеспечивают высокую интерактивность и удобство использования, а также позволяют поддерживать чистоту и структуру кода.

---

## 4. API
Данные для приложения получаются с API, доступного по адресу: [API Inspired](https://github.com/VladLesun/api-inspared). Это позволяет динамически загружать информацию о товарах и обновлять интерфейс в реальном времени. Использование **navigo** для маршрутизации обеспечивает управление навигацией внутри приложения SPA (Single Page Application) без перезагрузки страницы.

## Установка и запуск проекта
1. Клонируйте репозиторий:

 ``` bash
   git clone https://github.com/https://github.com/VladLesun/INSPIRED.git
 ``` 

2. Перейдите в папку проекта:

 ``` bash
   cd inspired
 ``` 

3. Установите зависимости:

 ``` bash
   npm install
 ``` 

4. Запустите проект:

 ``` bash
   npm start
 ```
